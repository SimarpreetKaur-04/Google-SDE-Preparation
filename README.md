for software engineering interview preparation.

- Arrays
- Strings
- Linked List
- Stack & Queue
- Trees
- Graphs
- Dynamic Programming
- Greedy

- Two Pointers & Sliding Window
- Bit Manipulation
- Matrix
- Segment Tree
- And more...

## Goal

This repository is used for practicing DSA problems and preparing
for coding interviews and software engineering placements.
